## Momentum Terimleri

| Terim (EN) | Türkçe | Tanım |
|------------|--------|-------|
| **Momentum** | Momentum | Performansın sürekliliği; geçmişte yükselen/düşen varlık aynı yönde devam etme eğilimindedir. |
| **Absolute momentum** | Mutlak momentum | Varlığın **kendi** fiyat geçmişine göre sürekliliği. (= Time-series / Longitudinal momentum) |
| **Relative momentum** | Göreceli momentum | Varlığın **diğer varlıklara** göre geçmiş performansı gelecek göreceli performansını öngörür. |
| **Relative strength** | Göreceli güç | Bir varlığın başka bir şeye göre performans gücü (Levy 1967 terimi). |
| **Dual momentum** | İkili momentum | Absolute + relative momentumun birleşimi. |
| **Cross-sectional** | Kesitsel | Belirli bir anda gruplar arası farkları karşılaştırma (= relative momentum bağlamı). |
| **Time-series momentum** | Zaman-serisi momentum | = Absolute momentum. |
| **Look-back / Formation period** | Geriye-bakış / Oluşum dönemi | Momentum sinyali için kullanılan önceki ay sayısı (GEM'de 12). |
| **Trend following** | Trend takibi | Geçmiş fiyatlarla piyasa yönünü belirleyen strateji (= absolute momentum). |

## Risk / Performans Terimleri

| Terim (EN) | Türkçe | Tanım |
|------------|--------|-------|
| **Sharpe ratio** | Sharpe oranı | (Getiri − Risksiz getiri) / std sapma. Birim risk başına getiri. |
| **Drawdown** | Düşüş | Fiyatın yeni zirveden düştüğü yüzde. |
| **Maximum drawdown** | Maksimum düşüş | Tüm geçmişte en büyük tepe-dip düşüşü. |
| **Excess return** | Aşırı getiri | Getiri − benchmark/risksiz getiri. |
| **Risk premium** | Risk primi | Risksiz oran üzerindeki getiri (risk tazminatı). |
| **Risk-free rate** | Risksiz oran | Sıfır riskli getiri (genelde T-Bill). |
| **Alpha** | Alfa | Risk-ayarlı anormal getiri (benchmark üstü). |
| **Beta** | Beta | Genel piyasa hareketlerine maruziyet riski. |
| **Standard deviation** | Standart sapma | Getirilerin ortalamadan dağılımı (volatilite). |
| **Volatility** | Volatilite | Veri serisinin hareket ölçüsü (= std sapma). |
| **Skewness** | Çarpıklık | Dağılımın simetrisi (negatif = uzun sol kuyruk). |
| **Kurtosis** | Basıklık | Kuyruk kalınlığı (yüksek = ekstrem getiri olasılığı). |
| **Fat-tailed / Leptokurtosis** | Kalın kuyruk | Ekstrem hareket olasılığı normalden yüksek. |
| **Tail risk** | Kuyruk riski | 3+ std sapma hareket riski. |
| **CVaR / Expected shortfall** | Koşullu RAD | Kayıp olduğunda beklenen kayıp. |
| **Tracking error** | İzleme hatası | Portföyün benchmark'tan sapması. |
| **Information ratio** | Bilgi oranı | (Getiri − benchmark) / tracking error. |
| **Sortino ratio** | Sortino oranı | Sadece downside volatilite kullanan Sharpe varyantı. |

## İstatistik / Modelleme Terimleri

| Terim (EN) | Türkçe | Tanım |
|------------|--------|-------|
| **Autocorrelation / Serial correlation** | Otokorelasyon | Getirilerin kendileriyle korelasyonu (farklı zamanlarda). |
| **Mean reversion** | Ortalamaya dönüş | Fiyat/getirinin zamanla ortalamaya geri dönmesi. |
| **Overfitting / Overspecification** | Aşırı uyum | Model gürültüyü tarif eder → kötü tahmin. |
| **Data mining** | Veri madenciliği | Geçmiş veride örüntü bulma. |
| **Data snooping / dredging** | Veri gözetleme | Veri madenciliğinin yanıltıcı ilişkiler için kötüye kullanımı. |
| **Curve fitting** | Eğri uydurma | Tesadüfi geçmiş örüntü (tekrarlamaz). |
| **In sample / Out-of-sample** | Örnek-içi / Örnek-dışı | Model kurulan veri / tamamen yeni veri. |
| **Ergodicity** | Ergodiklik | Her örneğin bütünü eşit temsil etmesi (piyasalar nonergodic). |
| **Stationary** | Durağan | Zamanla değişmeyen olasılık dağılımı (piyasalar nonstationary). |
| **Variance ratio (VR)** | Varyans oranı | k-dönem getiri / (k × 1-dönem varyans). VR>1 trending, <1 mean-reverting. |
| **Survivorship bias** | Hayatta kalma yanlılığı | Hayatta kalanlara odaklanıp başarısızları atlama. |
| **Backfill bias** | Geriye-doldurma yanlılığı | Sadece iyi performanstan sonra endekse ekleme. |
| **Selection bias** | Seçim yanlılığı | Nonrandom veri (veya başlangıç tarihi) seçimi. |
| **False discovery rate (FDR)** | Yanlış keşif oranı | Çoklu karşılaştırmada beklenen yanlış-pozitif yüzdesi. |
| **Bootstrap** | Bootstrap | Yeniden örnekleme tekniği (istatistik tahmini). |
| **Linear regression** | Doğrusal regresyon | Bağımlı-bağımsız değişken ilişkisi modeli. |
| **t-statistic** | t-istatistiği | İki veri setinin anlamlı farkı (>~2 anlamlı). |
| **Stochastic dominance** | Stokastik baskınlık | 2. derece: riskten kaçan, eşit-yüksek ortalama + daha öngörülebilir olanı tercih eder. |

## Portföy / Yatırım Terimleri

| Terim (EN) | Türkçe | Tanım |
|------------|--------|-------|
| **MPT** | Modern Portföy Teorisi | Risk için beklenen getiriyi maksimize etme teorisi. |
| **MVO** | Ortalama-Varyans Optimizasyonu | Geçmiş getiri/korelasyon/volatiliteyle optimal portföy. |
| **CAPM** | Sermaye Varlık Fiyatlama Modeli | Getiri ∝ beta. |
| **Capital market line** | Sermaye piyasası doğrusu | Risksiz orandan riskli varlıklara çizilen doğru. |
| **Separation theorem** | Ayrım teoremi | Portföy seçimi ile risk düzeyi kararını ayırır (Markowitz-Tobin). |
| **Efficient frontier** | Etkin sınır | Her risk düzeyinde en yüksek getirili portföyler. |
| **EMH** | Etkin Piyasa Hipotezi | Fiyatlar tüm kamu bilgisini yansıtır. |
| **Index fund** | Endeks fonu | Endeksi takip eden pasif fon (düşük gider, düşük devir). |
| **Capitalization weighted** | Piyasa-değeri ağırlıklı | Her hisse piyasa değeriyle ağırlıklanır. |
| **Equal weighted** | Eşit ağırlıklı | Her hisse eşit ağırlık. |
| **Smart/Strategic beta** | Akıllı/Stratejik beta | Kapitalizasyon-dışı kurallı ağırlıklandırma. |
| **Risk parity** | Risk paritesi | Varlıkları eşit volatiliteye ayarlama (genelde kaldıraçlı). |
| **Minimum variance portfolio** | Minimum varyans portföyü | En düşük volatiliteli riskli varlık seti. |
| **Leverage** | Kaldıraç | Getiri/volatiliteyi artırma (genelde borçla). |
| **Roll yield** | Roll getirisi | Kısa vadeli futures'ı uzun vadeye çevirmedeki getiri. |
| **Passive / Active management** | Pasif / Aktif yönetim | Benchmark takibi / sürekli yatırım seçimi. |

## Davranışsal Finans Terimleri

| Terim (EN) | Türkçe | Tanım |
|------------|--------|-------|
| **Behavioral finance** | Davranışsal finans | Psikolojinin yatırımcı davranışına etkisi. |
| **Anchoring** | Çıpalama | İlk bilgiye aşırı bağlılık, yavaş güncelleme → underreaction. |
| **Confirmation bias** | Doğrulama yanlılığı | Görüşü destekleyen bilgiye odaklanma. |
| **Conservatism** | Muhafazakârlık | Yeni kanıtla görüşü yetersiz güncelleme. |
| **Herding / Bandwagon** | Sürü davranışı | Başkaları yaptığı için yapma → overreaction. |
| **Overconfidence** | Aşırı güven | Yargısını olduğundan iyi sanma. |
| **Self-attribution bias** | Öz-atıf yanlılığı | Başarıyı kendine, başarısızlığı şansa yorma. |
| **Hindsight bias** | Geçmişi-bilme yanlılığı | Olay sonrası "zaten biliyordum" hissi. |
| **Disposition effect** | Disposition etkisi | Kazananı erken sat, kaybedeni tut. |
| **Loss aversion** | Kayıptan kaçınma | Kayıptan kaçınmayı kazançtan fazla önemseme. |
| **Asymmetric loss aversion** | Asimetrik kayıp kaçınması | Kayıpta risk al, kazançta riskten kaç. |
| **Prospect theory** | Beklenti teorisi | Kahneman-Tversky; kazanç ve kayıp farklı değerlenir. |
| **Representativeness** | Temsililik | Benzer olmayan olaylar arası paralellik kurma. |
| **Animal spirits** | Hayvani içgüdüler | Rasyonellik dışı duygusal davranış (korku-açgözlülük). |
| **Cognitive dissonance** | Bilişsel çelişki | İnançla çelişen kanıt karşısında rahatsızlık. |
| **Heuristic** | Sezgisel kural | Belirsizlikte karar için zihinsel kestirme. |
| **Noise** | Gürültü | Öngörülemez, tekrarlamayan örüntü (bilgiyle karıştırılır). |
